# NPASS link-only policy

Status: `LINK_ONLY_NO_REDISTRIBUTION`.

NPASS 2.0 and 3.0 source files are required local inputs. This repository
provides official links, recorded file sizes and SHA-256 checksums, and
project-authored download and transformation code. It does not host or include
NPASS source files or row-level derivatives.

Excluded material includes NPASS identifiers, structures, activity records,
target–compound–PMID mappings, row-level subsets, and combinations of fields
that could reconstruct NPASS records. Generated frozen row-level inputs remain
local and are not release artifacts.

The open-access licence of an NPASS article is not treated as a licence for the
database contents. No NPASS redistribution permission is claimed. Users obtain
the files directly from the official NPASS download page and are responsible
for complying with the provider's current terms.

This repository is not affiliated with or endorsed by the NPASS database or
its maintainers.
